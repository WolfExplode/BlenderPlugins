# BlenderPlugins

A collection of Blender add-ons and scripts for rigging, weight painting, animation, and viewport tools.

**[Browse the add-on list →](https://wolfexplode.github.io/BlenderPlugins/)**

## Add-ons

| Add-on | Category | Description |
|---|---|---|
| [Bone Renamer](BoneRenamer_v1.2) | Rigging | Rename armature bones between naming conventions; JP→EN translation |
| [Bweight](Bweight) | Paint | Keyboard-driven weight smooth/sharpen/grow/shrink + scoped auto-normalize |
| [Variable Playback Baker](cyclic%20animation) | Animation | Bake cyclic animation with BPM-driven variable playback speed |
| [Import Export Geo Nodes](ExportImportGeoNodes) | Node | Export/import Geometry Nodes trees via JSON |
| [Gizmo Plus](gizmo_plus) | 3D View | Keeps the transform gizmo on screen when its object is off-view |
| [Guard Edit Mode for MACHIN3tools](Guard%20Edit%20Mode%20for%20MACHIN3tools) | System | Blocks Edit Mode on meshes over a vertex threshold |
| [HDRi Maker](hdri_maker) | 3D View | Browse and apply HDRIs with world controls |
| [Open Console on Startup](Open_console_on_startup.py) | System | Opens the system console on the second monitor at startup |
| [ScreenshotNodes](ScreenshotNodes) | Node | High-quality, auto-stitched screenshots of a node tree |
| [Symmetrize Plus](Symmetrize_Plus) | Mesh | Symmetrize with a flick gizmo (Edit Mesh / Sculpt / Weight Paint) |
| [Target, Please!](Target%20Please) | Object | Tracking target with a smart orbit pivot for cameras/lights |
| [translateShapekeysToEnglish](translateShapekeysToEnglish) | Rigging | Translates Japanese shape key names to English |
| [World-Space Brush](world-space%20brush) | Paint | Keeps texture-paint brush size constant in world units |

Older, unmaintained add-ons live in [`/Archive`](Archive) for reference.

## Installation

Each add-on is a single file or self-contained folder. Download it, then in Blender go to
`Edit → Preferences → Add-ons → Install…` and select it (zip the folder first if it has multiple
files). Enable the checkbox to activate.
