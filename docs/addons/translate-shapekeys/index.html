translateShapekeysToEnglish

Docs (README) Source

Overview

Rename Japanese shape keys (common in MMD-imported models) to their English equivalents using a built-in lookup table.

UI Location

See script for the exact operator/menu entry (operator search: “translate shape keys”).

Features

  • Lookup table translation: Matches shape key names against a table of common Japanese facial/expression terms (chin, cheek, eye, mouth, smile, angry, etc.) and renames them to English.

Usage

  1. Select a mesh with Japanese-named shape keys.
  2. Run the translate operator to rename matching shape keys to English.
