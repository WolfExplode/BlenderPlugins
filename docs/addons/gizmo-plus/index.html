Gizmo Plus

Docs (README) Source

Overview

Keeps the transform gizmo pinned on screen when its object moves out of view. This Softimage-style transform manipulator inspired by @cvELD_info.

UI Location

3D Viewport → active whenever the transform gizmo is shown.

Features

  • Pinned gizmo: The transform gizmo stays visible on screen even when its object is off-viewport.

Usage

  1. Enable the addon and select an object with the move/rotate/scale gizmo active.
  2. When you pan or zoom the object off-screen. The gizmo stays pinned on screen so you can keep transforming it.
