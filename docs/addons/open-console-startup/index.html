Open Console on Startup

Source

Overview

Opens the system console (Windows) on the second monitor, top-left, whenever Blender starts.

UI Location

No panel — runs automatically on Blender startup (Windows only).

Features

  • Auto-open on startup: Opens the Windows system console automatically when Blender launches.
  • Second-monitor placement: Positions the console window on the second monitor, top-left corner.

Usage

  1. Install the single-file script as an addon and enable it.
  2. Restart Blender — the system console opens automatically on the second monitor.
