BlenderPlugins

A collection of small Blender add-ons and scripts — rigging, weight painting, animation, and viewport tools — built to smooth out day-to-day workflow gaps.

Source on GitHub Installation

Installation

Each add-on below is a single file or self-contained folder — no shared dependencies between them. Download the file/folder, then in Blender go to Edit → Preferences → Add-ons → Install… and pick it (zip the folder first if it contains multiple files). Enable the checkbox to activate.

Rigging
